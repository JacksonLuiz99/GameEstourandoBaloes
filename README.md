# 🎈 Game: Estourando Balões

Bem-vindo ao **Estourando Balões**, um jogo simples, divertido e desafiador desenvolvido para testar sua agilidade! O objetivo é estourar o maior número de balões possível antes que o tempo acabe.

## 🚀 Como Jogar

1.  **Escolha o Nível**: Na tela inicial, selecione o nível de dificuldade desejado:
    *   **Easy**: 120 segundos (Ideal para iniciantes).
    *   **Medium**: 60 segundos (Para quem busca um desafio equilibrado).
    *   **Hard Core**: 30 segundos (Apenas para os mais rápidos!).
2.  **Inicie o Jogo**: Clique no botão "Iniciar" para começar a contagem regressiva.
3.  **Estoure os Balões**: Clique nos balões azuis no cenário para estourá-los.
4.  **Vença o Jogo**: Ganhe ao estourar todos os balões antes do cronômetro zerar.
5.  **Tente Novamente**: Se o tempo acabar e você não conseguir estourar todos, clique em "Jogue Novamente" para recomeçar.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias web fundamentais:

*   **HTML5**: Estruturação semântica de todo o conteúdo e interface do jogo.
*   **CSS3**: Estilização visual, layouts e posicionamento dos elementos (atualmente em transição para Tailwind CSS).
*   **JavaScript (Vanilla)**: Lógica de jogo pura, incluindo manipulação do DOM, controle do cronômetro e detecção de cliques.

## 📈 Pontos de Melhoria Identificados

Para elevar a experiência do usuário e a qualidade do código, foram mapeadas as seguintes melhorias:

*   **Responsividade**: Implementação de Flexbox/Grid para garantir que o jogo funcione bem em diferentes tamanhos de tela.
*   **Modernização do Design**: Substituição de tabelas e floats legados por Tailwind CSS para um visual mais "Premium".
*   **Feedback do Usuário**: Melhoria nas mensagens de "Game Over" e remoção de alertas obstrutivos.
*   **Dificuldade Dinâmica**: Alterar não apenas o tempo, mas também a quantidade de balões de acordo com o nível escolhido.
*   **Performance e Segurança**: Refatoração do código JavaScript para evitar o uso de `eval()` implícito e melhorar a legibilidade.
