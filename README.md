# 🎈 Game: Estourando Balões

Bem-vindo ao **Estourando Balões**, um jogo moderno, divertido e desafiador desenvolvido para testar sua agilidade! O objetivo é estourar todos os balões no cenário antes que o cronômetro chegue ao fim.

## 🚀 Como Jogar

1.  **Escolha o Nível**: Na tela inicial, selecione o nível de dificuldade:
    *   **Easy**: 120 segundos e 60 balões (Ideal para iniciantes).
    *   **Medium**: 60 segundos e 80 balões (O desafio padrão).
    *   **Hard Core**: 30 segundos e 100 balões (Apenas para os mais rápidos!).
2.  **Inicie o Jogo**: Clique no botão "Iniciar Jogo".
3.  **Estoure os Balões**: Clique nos balões azuis no cenário. Os balões estourados mudarão de cor e ficarão semitransparentes.
4.  **Vença o Jogo**: Ganhe ao estourar todos os balões (`Inteiros: 0`) antes do tempo acabar.
5.  **Tente Novamente**: Se o tempo esgotar, você pode clicar em "Reiniciar" para tentar superar o desafio.

## 🛠️ Tecnologias Utilizadas

O projeto foi totalmente modernizado com as seguintes tecnologias:

*   **HTML5**: Estruturação semântica e acessível.
*   **Tailwind CSS**: Estilização premium com layout flexível, responsivo e estética moderna (Dark mode).
*   **Google Fonts (Outfit)**: Tipografia otimizada para uma experiência visual refinada.
*   **JavaScript (ES6+)**: Lógica de jogo limpa, utilizando `let`/`const`, arrow functions e manipulação dinâmica do DOM.

## ✨ Destaques da Modernização

Recentemente o projeto passou por uma reformulação completa para garantir:

*   **Responsividade**: O jogo se adapta perfeitamente a diferentes tamanhos de tela.
*   **Estética Premium**: Uso de gradientes, sombras e animações suaves para um visual profissional.
*   **Dificuldade Equilibrada**: A dificuldade agora influencia tanto o tempo disponível quanto a densidade de balões.
*   **Acessibilidade**: Adição de atributos `alt` em imagens e melhorias na hierarquia de elementos.
